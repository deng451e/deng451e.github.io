# deng451e.github.io

Personal website of Weishu Deng — https://deng451e.github.io

Static HTML/CSS, no build step. Edit `index.html` / `style.css` and push to `main`;
GitHub Pages redeploys automatically. Bump the `style.css?v=N` query in `index.html`
whenever the stylesheet changes so browsers don't serve a stale copy.
